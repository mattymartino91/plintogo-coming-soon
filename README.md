# PLIN — The Italian Social Club

Static, responsive website ready for GitHub Pages.

## Publish

Upload the contents of this folder to the root of the existing GitHub Pages repository. Keep `CNAME` in the root. No build step or dependencies are required.

The supplied interior images were used only as visual references and are not included in this package.

The header and footer use the supplied PLIN wordmark, including the original descending `N`, extracted onto a transparent background.
